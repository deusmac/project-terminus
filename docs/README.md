# docs/ - Terminus project documents

Created 2026-07-12 from a full end-to-end audit. Reading order for any new agent or
session:

1. ../CLAUDE.md - project memory, landmines, guardrails. Always first.
2. PRODUCT.md - what Terminus is, current honest state, phased roadmap with acceptance
   criteria. This drives what to do next.
3. AGENT-BRIEF.md - how to think and work on this project (the mentality file, applies
   THINKING.md to Terminus specifics).
4. AUDIT-2026-07-12.md - every defect found in the full audit, ranked by severity, with
   exact fixes and line numbers.

Keep these current: when a roadmap phase lands, mark it done in PRODUCT.md; when an audit
finding is fixed, note the fix date next to it rather than deleting it.

Data Sources & Verification

ENGINEERING BASIS: Heights computed live from SSMA-published effective section properties (Ixe, Ma, E = 29,500 ksi) per AISI S100 — deflection: L = (384·E·Ixe / 5·w·n)1/3; flexure: L = (8·Ma / w)1/2; lesser governs. Engine output validated against published SSMA / Steel-Con limiting-height tables (exact match incl. the 0.70 wind-deflection provision). CEILING / SOFFIT SPANS: not computed — read directly from the SSMA published span tables (S-section joists pp.62–67, hat furring channel p.68, U-channel p.69). Loads are total load acting up or down on the ceiling; a cell SSMA does not publish reads N/R rather than being interpolated. DISCLAIMER: A bidding study tool — not a substitute for the EOR. Rows marked VERIFIED carry SSMA-published properties; rows marked ESTIMATE (proprietary EQ lines) must be confirmed against the linked manufacturer catalog and ICC-ES report before submittal. Rows marked CALC (10" and 12" webs, and 2-1/2" and 3" flanges) have SSMA section properties but no SSMA-published height table — the height is this engine's own, so confirm with the EOR before it goes in front of a GC.
